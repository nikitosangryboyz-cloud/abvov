# VK Composition Archetypes V2

This is the compact lookup library derived from the supplied reference boards. Use it when selecting a composition before designing a new VK cover.

## CT-01 — Left Type / Right Hero

**Structure:** typography mass on left, large portrait/product/environment on right.

**Primary zones:**
- Headline: X 8–45%, Y 20–65%.
- Hero: X 48–100%, Y 0–100%.
- Eyebrow: X 8–40%, Y 7–20%.
- Support: X 10–45%, Y 65–85%.

**Best for:** services, personal brands, products, automotive, education.

---

## CT-02 — Center Subject / Split Type

**Structure:** central person/object framed by typography and information on both sides.

**Primary zones:**
- Subject: X 40–63%, Y 5–100%.
- Left title: X 12–42%, Y 25–65%.
- Right info/title: X 60–88%, Y 25–70%.
- Top labels: Y 7–20%.

**Best for:** personal brands, tattoo artists, beauty, expert profiles.

---

## CT-03 — Center Brand / Symmetric Products

**Structure:** brand at top center, two or more large products/vehicles below.

**Primary zones:**
- Logo: X 30–70%, Y 7–28%.
- Subhead: X 35–65%, Y 23–38%.
- Product group: X 5–95%, Y 35–95%.
- Metadata: Y 86–98%.

**Best for:** automotive, retail, product catalogs.

---

## CT-04 — Full Scene / Embedded Headline

**Structure:** one cinematic environment with text integrated into open space.

**Primary zones:**

- Main subject: X 48–100%, Y 0–100%.
- Tags/proof: X 20–60%, Y 58–88%.

**Best for:** travel, real estate, restaurants, services.

# Selection rule

Choose the archetype based on **spatial logic**, not on industry.

Example:

```text
Reference has:
large person right + huge type left

→ CT-01

Reference has:
central person + text on both sides

→ CT-02

Reference has:
logo top + two vehicles/products below

→ CT-03
```

The same archetype may be used for completely different industries.

# Adaptation rule

When adapting a reference to a new niche:

1. keep archetype;
2. keep relative element positions;
3. keep visual weight distribution;
4. keep headline hierarchy;
5. replace subject/content;
6. replace palette only if required by the new brand;
7. preserve negative-space logic;
8. preserve depth and crop behavior.
