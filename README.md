# VK Design Studio

Production system for creating VK community visual identities from references.

## Core workflow

Reference → Reverse Engineering → Composition Blueprint → Content Adaptation → Figma → Quality Control

## Repository structure

```text
01_REFERENCE_LIBRARY/
02_COMPOSITION_SYSTEM/
03_VK_FORMATS/
04_DESIGN_RULES/
05_TYPOGRAPHY/
06_ICONS/
07_PROMPTS/
08_PROJECTS/
```

## Source architecture

The repository architecture is inspired by the structure of an existing open-source social-media brand system, while the content and composition rules here are purpose-built for our VK design workflow.
