# MASTER REFERENCE ANALYSIS — VK COVER PORTFOLIO

## 0. Purpose

This file is the **single visual source of truth** for creating new VK covers as a continuation of the user's existing portfolio.

The supplied reference set contains many completed VK covers from different niches: tattoo studios and artists, beauty/cosmetology, gaming stores, automotive, food, real estate, education, services, personal brands, events, B2B, etc.

The important commonality is **not one fixed style or color palette**.

The commonality is the **way the cover is constructed**.

### Core rule

A new cover must look like it could naturally sit next to the supplied works.

It must NOT look like:
- a generic AI advertising banner;
- a standard Canva template;
- a random Behance-inspired design;
- a universal "modern marketing" layout;
- a cover with invented blocks, icons, cards and benefits.

The niche changes.

The visual construction language remains.

---

# 1. FORMAT

The supplied covers consistently use a very wide horizontal banner format corresponding to the VK desktop-cover proportion.

Target working canvas:

**1920 × 768 px**

Aspect ratio:

**2.5 : 1**

The design is built as one continuous cinematic composition, not as a collection of independent UI cards.

---

# 2. GLOBAL COMPOSITION PRINCIPLE

The portfolio is built around three visual layers:

### Layer A — Environment / background

This is the atmospheric world of the cover.

Examples visible in the references:
- tattoo studio interiors;
- dark textured walls;
- smoke;
- architectural environments;
- landscapes;
- vehicles and roads;
- gaming environments;
- beauty interiors;
- food/product environments;
- abstract textures;
- paper / editorial textures;
- light studio environments.

The background is rarely a flat color.

Even when the background is visually simple, it normally contains:
- texture;
- photographic depth;
- gradients;
- environmental objects;
- soft light;
- shadows;
- particles;
- patterns;
- atmospheric haze.

### Layer B — Main subject

Usually one dominant visual subject:

- person;
- product;
- vehicle;
- building;
- device;
- food;
- equipment;
- group of people.

The subject is normally large enough to become the second thing noticed after the main headline.

### Layer C — Typography / information

Typography is integrated into the image rather than placed on top like a standard website hero.

Text can:
- overlap the subject;
- sit beside the subject;
- sit behind the subject;
- occupy a large empty area;
- extend across the central composition;
- be partially integrated into the background.

---

# 3. THE MOST IMPORTANT RULE: TEXT + IMAGE ARE ONE COMPOSITION

Do NOT create:

> background + person on right + text block on left + three cards

unless the reference family actually requires that structure.

In the supplied portfolio, text frequently interacts with the image.

Examples of observed behavior:
- large typography crossing behind a person;
- subject placed between words;
- title centered around a face;
- title occupying the left half while subject occupies the right;
- title spanning almost the entire width;
- very large typography becoming a visual object itself;
- typography deliberately touching or approaching the subject;
- asymmetric text placement.

The text is not an independent information panel.

It is part of the image.

---

# 4. PRIMARY HEADLINE

The main headline is the strongest textual element.

Typical behavior:

- 1 main headline;
- sometimes 2 lines;
- occasionally 3 short lines;
- large scale;
- strong contrast;
- often condensed / display typography;
- sometimes elegant high-contrast serif;
- sometimes handwritten/script;
- sometimes wide geometric sans;
- sometimes distressed or custom-looking lettering.

### Important

There is **no single portfolio font**.

The references deliberately adapt typography to the character of the project.

Observed families include:
- condensed display;
- bold grotesk;
- elegant serif;
- editorial serif;
- handwritten/script;
- brush lettering;
- geometric sans;
- custom / distressed display lettering.

Therefore:

**Do not force one font on every cover.**

Instead match the typographic character of the closest reference family.

---

# 5. HEADLINE SCALE

The headline often occupies approximately:

**25–55% of the visual width**

depending on the composition.

It is intentionally oversized.

The main title is allowed to become an image-like element.

Examples from the references:
- `SPIRIT TATTOO`;
- `BLACK ART`;
- `GAMER`;
- `XBOX STORE`;
- `INNA KOLET`;
- `ТАТУ-СТУДИЯ`;
- `ПРИРОДНЫЙ КАМЕНЬ`;
- `АРЕНДА ДОМА С БАНЕЙ`;
- `МЕДИЦИНСКИЙ ЦЕНТР`;
- `ПРОДАЖИ`.

The important property is not the wording.

It is the **visual weight**.

---

# 6. TEXT HIERARCHY

Most covers use a small number of text levels.

### Level 1 — Main name / headline

Dominant.

### Level 2 — Descriptor

Examples:
- tattoo artist;
- tattoo studio;
- professional artist;
- service category;
- short positioning statement.

Usually significantly smaller than the headline.

### Level 3 — Supporting facts

Only when useful:
- city;
- years of experience;
- number of works;
- specialization;
- short benefit;
- contact;
- price;
- short service description.

### Level 4 — Microtext

Very small utility information may appear, but it is subordinate.

### Rule

Do not invent 6–10 information blocks simply because space exists.

The references usually communicate the offer with **a compact hierarchy**.

---

# 7. TEXT POSITIONING PATTERNS

The portfolio repeatedly uses several real positioning patterns.

## A. LEFT TEXT / RIGHT SUBJECT

Text occupies left third or left-center.

Main subject occupies right side.

Very common.

## B. RIGHT TEXT / LEFT SUBJECT

Reverse version.

Used when the subject naturally points toward or occupies the left side.

## C. CENTRAL TITLE + SUBJECT OVERLAP

Large title spans the middle.

Person or product overlaps the typography.

## D. FULL-WIDTH TYPOGRAPHIC TITLE

Large title stretches across the composition.

Subject interrupts the title.

## E. SPLIT COMPOSITION

Two visual zones with a strong vertical division.

Each side may contain:
- text;
- subject;
- secondary information.

## F. EDITORIAL ASYMMETRY

Large empty area on one side.

Subject placed away from center.

Typography balances the empty area.

These are **composition families**, not mandatory templates.

For every new cover choose the family that best matches the supplied references for the new niche.

---

# 8. SUBJECT POSITION

The main person/object is rarely placed as a tiny centered portrait.

Common scale:

**large / medium-large**

The subject usually occupies roughly:

**30–55% of the canvas height**

and can occupy more when it is the central hero.

The subject may:
- extend above/below the optical text zone;
- be cropped by the canvas;
- overlap typography;
- overlap decorative objects;
- sit in foreground;
- be partially hidden by atmosphere.

### People

People are usually presented as:
- cutout or semi-cutout;
- strongly integrated into the background;
- professionally lit;
- with controlled edge separation;
- with cinematic color treatment.

Avoid:
- generic stock-photo appearance;
- tiny headshots;
- perfectly centered passport-like portraits.

---

# 9. MULTIPLE PEOPLE

When several people are present, they are normally treated as a **group composition**, not as separate profile cards.

Common structures:
- one dominant central person + secondary people;
- two people facing inward;
- several people forming a horizontal group;
- people distributed around a central title.

The group must read as one image.

---

# 10. PRODUCT / OBJECT COVERS

For products, the product becomes the hero.

Observed examples include:
- game consoles;
- controllers;
- cars;
- equipment;
- food;
- building materials;
- beauty products.

Product treatment:
- large scale;
- strong lighting;
- realistic material;
- integrated shadows;
- atmospheric background;
- sometimes multiple product instances.

Avoid:
- tiny isolated product floating in empty space;
- generic e-commerce product-card treatment.

---

# 11. BACKGROUND LANGUAGE

The supplied references use highly varied backgrounds, but they share a few behaviors.

### Dark references

Frequently use:
- black;
- charcoal;
- deep brown;
- dark green;
- dark blue;
- burgundy;
- deep purple.

With:
- glow;
- haze;
- texture;
- smoke;
- gradients;
- photographic detail;
- subtle patterns.

### Light references

Frequently use:
- white;
- warm white;
- cream;
- pale blue;
- pale pink;
- light beige.

With:
- soft photography;
- low-contrast texture;
- delicate gradients;
- translucent shapes;
- soft shadows.

### Important

The portfolio does NOT have one mandatory color palette.

Color follows the brand / niche / concept.

---

# 12. ACCENT COLORS

Accent color is usually used selectively.

Observed behavior:
- red on dark compositions;
- cyan/teal on dark tattoo compositions;
- purple/magenta for beauty or creative projects;
- green for gaming / Xbox;
- yellow for automotive / construction / business;
- blue for technology / medical / automotive;
- gold / bronze for premium/editorial compositions.

Accent color often appears in:
- one word of the headline;
- a button;
- a label;
- a line;
- a badge;
- a small icon;
- a secondary object.

Avoid turning every element into an accent.

---

# 13. CTA / BUTTONS

CTA elements exist in the references, but they are compact.

Typical forms:
- pill;
- rounded rectangle;
- small highlighted label;
- dark translucent tag;
- colored button;
- text inside a compact badge.

They are NOT giant website buttons.

A CTA should normally be a supporting element, not the main visual.

---

# 14. BADGES / LABELS / FACTS

The portfolio frequently uses small information chips.

Examples:
- location;
- years of experience;
- number of works;
- specialization;
- price;
- service;
- short promise.

Typical placement:
- close to the relevant subject;
- in empty space;
- near a corner;
- around the main composition.

They are usually small and subordinate.

---

# 15. ICONS

Icons are used selectively.

When present:
- simple;
- small;
- supporting information;
- usually inside a badge or compact information element.

The portfolio does NOT rely on large icon grids as a primary design language.

Therefore do not automatically add:
- 3 benefit icons;
- 6 service icons;
- feature grids.

Only use them when the reference family supports them.

---

# 16. DECORATIVE ELEMENTS

Common decorative language across the portfolio:

- texture;
- grain;
- smoke;
- light streaks;
- glow;
- particles;
- scratches;
- paper;
- brush marks;
- geometric lines;
- environmental objects;
- thematic patterns;
- frames;
- subtle borders.

The decorative layer normally supports the theme.

It should not become a collection of random AI decorations.

---

# 17. DEPTH

Depth is one of the strongest recurring properties.

Typical depth stack:

1. distant background;
2. atmospheric texture;
3. secondary objects;
4. main subject;
5. typography;
6. foreground elements / glow / particles.

Objects can overlap each other.

Blur is used to separate depth planes.

Foreground objects may be partially cropped.

---

# 18. LIGHTING

Lighting is cinematic rather than flat.

Common behaviors:
- rim light around people;
- colored edge light;
- central glow;
- backlight;
- volumetric haze;
- highlights on products;
- dark vignette;
- soft bloom.

Lighting often connects the subject to the background.

Do not simply paste a cutout on a background.

---

# 19. PHOTO TREATMENT

The portfolio frequently uses photographs that are heavily integrated into the composition.

Typical treatment:
- background removal;
- color grading;
- contrast adjustment;
- glow;
- haze;
- shadow;
- edge light;
- atmospheric blending;
- partial transparency in background imagery.

The person/object should appear to belong to the environment.

---

# 20. NEGATIVE SPACE

Negative space is actively used for typography.

Important:

Do not fill every empty area.

Empty space can exist specifically so that:
- the headline remains readable;
- the subject becomes dominant;
- the composition breathes;
- a secondary fact can sit there.

---

# 21. INFORMATION DENSITY

The portfolio has **medium to high visual information density**, but the information is organized around one dominant message.

Typical priority:

**MAIN MESSAGE → SUBJECT → SECONDARY MESSAGE → SMALL FACTS**

Not:

**10 equal pieces of information.**

The viewer should understand the cover in approximately one glance.

---

# 22. WHAT THE PORTFOLIO DOES NOT WANT

These rules are especially important for future AI generation.

DO NOT automatically add:

- generic 3-card benefits;
- generic "Почему мы";
- FAQ;
- huge website-style CTA;
- floating glassmorphism cards;
- random 3D icons;
- random arrows;
- random circles;
- generic abstract blobs;
- unnecessary UI panels;
- excessive gradients;
- dozens of tiny labels;
- fake statistics;
- meaningless decorative text;
- stock business illustrations;
- generic corporate iconography;
- symmetrical template layouts when the reference is asymmetric;
- overly clean Canva-like blocks;
- excessive rounded cards inside the banner;
- random "premium" gold details;
- fake logos;
- fake brands;
- invented services.

---

# 23. WHAT MAKES THE REFERENCES FEEL LIKE ONE PORTFOLIO

Despite huge differences in niche, the covers repeatedly share:

### 1. Strong hero

One visual idea dominates.

### 2. Large typography

The title is visually important.

### 3. Integrated imagery

Text and image are composed together.

### 4. Cinematic depth

Background, subject and foreground have different planes.

### 5. Compact supporting information

Small facts support the main message instead of competing with it.

### 6. Theme-specific art direction

Tattoo ≠ beauty ≠ automotive ≠ gaming.

The visual language changes, but the **composition discipline** remains.

### 7. High contrast

The main message is readable at a glance.

### 8. Custom feel

The references rarely look like a stock template with text replaced.

---

# 24. PORTFOLIO COMPOSITION DNA

Use this as the compact rule set when creating a new cover:

> ONE HERO IDEA  
> ONE DOMINANT HEADLINE  
> ONE DOMINANT SUBJECT  
> 1–3 SUPPORTING INFORMATION GROUPS  
> CINEMATIC ENVIRONMENT  
> CONTROLLED DEPTH  
> STRONG TYPOGRAPHIC SCALE  
> ASYMMETRY WHEN APPROPRIATE  
> THEME-SPECIFIC ART DIRECTION  
> NO GENERIC TEMPLATE ELEMENTS

---

# 25. NEW COVER GENERATION ALGORITHM

For every new client brief:

## Step 1 — Identify the niche

Example:

`Ремонт квартир в Краснодаре`

## Step 2 — Identify the closest reference families

Do not copy one cover.

Find 2–4 references with similar:
- information density;
- subject type;
- business/personal positioning;
- visual mood;
- text hierarchy.

## Step 3 — Extract the composition

Write down:

- canvas;
- main headline zone;
- subject zone;
- secondary information zone;
- CTA zone;
- decorative zones;
- negative space;
- visual center.

## Step 4 — Replace the content

Only change:
- company/person;
- niche;
- city;
- services;
- relevant visual subject;
- color direction when necessary.

## Step 5 — Rebuild the visual world

For the new niche, create:
- correct environment;
- correct objects;
- correct lighting;
- correct texture;
- correct atmosphere.

## Step 6 — Rebuild typography

Use the closest typographic character from the references.

Do not blindly reuse a font if it does not fit.

## Step 7 — Remove unnecessary elements

Before finalizing, ask:

**"Was this element actually supported by the reference portfolio?"**

If no → remove it.

---

# 26. FINAL QUALITY CHECK

A generated cover passes only if:

### Composition
- [ ] There is one clear visual focal point.
- [ ] The headline has dominant visual weight.
- [ ] Subject and typography interact.
- [ ] There is intentional negative space.
- [ ] The composition is not a generic left-text/right-person template.

### Typography
- [ ] Main headline is immediately readable.
- [ ] Text hierarchy is clear.
- [ ] There are no unnecessary text blocks.
- [ ] Typography matches the closest reference family.

### Imagery
- [ ] Main subject is large enough.
- [ ] Subject is integrated into the environment.
- [ ] Lighting matches the scene.
- [ ] No stock-photo pasted-on appearance.

### Information
- [ ] Only useful supporting information remains.
- [ ] CTA is compact.
- [ ] Badges are subordinate.
- [ ] No invented marketing blocks.

### Portfolio continuity
- [ ] It could sit naturally next to the supplied references.
- [ ] It looks like a new work from the same designer.
- [ ] It does NOT look like a generic AI banner.
- [ ] It does NOT look like a copy of one specific reference.
