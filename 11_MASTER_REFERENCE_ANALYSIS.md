# MASTER REFERENCE ANALYSIS

## Purpose

This file is the **single source of truth for the user's own VK cover portfolio**.

The user will provide a complete set of their existing covers. We will analyze **only those supplied works** and extract the recurring visual and structural rules that make the portfolio feel like the work of one designer.

This is NOT a generic VK design guide and NOT an industry template library.

## Critical rule

Do not add assumptions from generic design knowledge when the supplied portfolio does not support them.

Do not invent elements, sections, CTA patterns, icons, badges, benefits, or decorative devices.

Do not analyze or copy one cover in isolation when the goal is portfolio continuity.

The final goal is:

> Create a new cover that looks like a natural continuation of the user's existing portfolio.

## Analysis scope

After the complete reference set is supplied, document only what is actually present and recurring across the works:

### 1. Canvas / format
- dimensions when known;
- aspect ratio;
- recurring margins and safe areas;
- recurring spatial proportions.

### 2. Text system
For every recurring text role, identify:
- what text exists;
- hierarchy;
- approximate size relationship;
- position;
- alignment;
- line count;
- capitalization;
- weight/width character;
- recurring typography behavior.

Do NOT invent font names unless they can be established from the supplied materials.

### 3. Image / hero system
Identify:
- what kinds of hero subjects recur;
- subject scale;
- subject placement;
- cropping;
- overlap with typography;
- foreground / middle / background behavior;
- photographic vs 3D treatment;
- recurring lighting behavior.

### 4. Supporting information
Record only information elements actually present in the portfolio:
- labels;
- location;
- credentials;
- services;
- contact details;
- badges;
- CTA;
- small utility text.

Record their typical quantity and placement.

### 5. Decorative language
Identify recurring:
- lines;
- frames;
- textures;
- particles;
- glows;
- patterns;
- illustrations;
- graphic marks;
- overlays.

Do not add decorations merely because they fit an industry.

### 6. Color behavior
Extract recurring behavior rather than prescribing a fixed palette:
- dominant background tendencies;
- accent behavior;
- contrast;
- light/dark balance;
- color relationships between typography and hero imagery.

### 7. Depth / atmosphere
Record recurring:
- cinematic depth;
- blur;
- haze;
- glow;
- shadows;
- texture;
- foreground elements;
- environmental integration.

### 8. Composition behavior
Identify recurring patterns across the entire portfolio:
- left/right balance;
- centered compositions;
- asymmetric compositions;
- hero subject relationships;
- typography-image interaction;
- negative space;
- visual focal point;
- information density.

### 9. What is NOT present
This section is mandatory.

List patterns that the portfolio consistently avoids, so future generations do not introduce generic AI-banner elements that are absent from the user's work.

### 10. Portfolio DNA
Conclude with a compact set of evidence-based rules describing the shared visual language of the whole reference set.

## Future generation protocol

Before creating any new VK cover:

1. Read this file.
2. Read the complete supplied reference set / analysis.
3. Treat the user's portfolio as the primary visual source.
4. Determine the minimum content required by the new client brief.
5. Build a fresh composition using only the documented portfolio DNA.
6. Do not add generic marketing elements unless the portfolio demonstrates them.
7. Check the result against the portfolio as a whole.
