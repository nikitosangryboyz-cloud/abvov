# MASTER STYLE CONTINUATION

## Core objective

The attached reference covers are the user's own portfolio and represent the target visual language for future work.

The goal is NOT to copy one reference literally and NOT to invent a generic industry template.

The goal is to create a **new cover that looks like a natural continuation of the user's existing body of work** — as if it belongs in the same portfolio and was designed by the same designer.

## What future generations must preserve

Across the reference set, preserve the author's recurring design language:

- cinematic, art-directed hero imagery;
- strong photographic or 3D subject matter;
- large expressive typography;
- deliberate asymmetric or central compositions;
- layered depth rather than flat card layouts;
- integrated text and imagery;
- controlled contrast and accent colors;
- atmospheric backgrounds;
- secondary information integrated into the composition;
- small labels, badges and utility information used selectively;
- rich material/texture treatment where appropriate;
- clear focal point and visual hierarchy;
- premium advertising / editorial feeling;
- a finished, authored composition rather than a UI template.

## What must NOT happen

Do not reduce the style to generic category clichés.

Avoid:

- generic "AI advertising banner" layouts;
- modular website-like cards placed on a background;
- excessive icon rows;
- repetitive benefit blocks;
- arbitrary calculators/CTA boxes;
- decorative objects added only because they represent the industry;
- floating unrelated tools around the canvas;
- predictable symmetrical three-column layouts unless a reference clearly uses them;
- excessive pills and badges;
- stock-looking compositions;
- generic black + gold renovation aesthetics;
- literal visual metaphors replacing art direction;
- copying one reference's exact content or artwork.

## Reference-set principle

A new design should be evaluated against the **whole reference set**, not against one isolated cover.

The reference set defines the designer's visual DNA.

Before generating a new cover, identify:

1. recurring composition patterns;
2. recurring typography behavior;
3. recurring image treatment;
4. recurring depth and lighting behavior;
5. recurring information density;
6. recurring use of decorative elements;
7. recurring relationship between subject and typography;
8. recurring balance of realism, graphic design and atmosphere.

Then create a new composition using those principles.

## New-project workflow

### Step 1 — Study the reference set

Treat the user's attached portfolio as the primary source of truth.

### Step 2 — Extract the visual DNA

Do not only extract coordinates. Extract the higher-level design behavior:

- how much of the canvas is occupied by the hero subject;
- how typography interacts with the subject;
- where visual weight normally sits;
- how much negative space is tolerated;
- how information is distributed;
- how backgrounds are constructed;
- how depth is created;
- how accents are introduced;
- how a cover avoids looking like a template.

### Step 3 — Select a compatible composition family

Choose a composition archetype from the reference library, but do not mechanically reproduce it.

Use the archetype as a structural starting point and generate a fresh composition that belongs to the same portfolio.

### Step 4 — Adapt to the client's niche

Change the subject matter, photography/3D, copy, color accents and supporting details while preserving the author's design language.

### Step 5 — Generate

The final image should feel like:

> **"another work from the same designer"**

rather than:

> **"an AI image inspired by a random reference."**

## Quality gate

Before accepting a result, ask:

### Portfolio continuity

Could this cover be placed next to the user's references without looking like it came from a different designer?

### Authorship

Does it feel intentionally art-directed rather than assembled from generic components?

### Composition

Is there one clear dominant composition instead of a collection of independent blocks?

### Typography

Does typography have personality and participate in the composition?

### Imagery

Does the hero imagery feel integrated into the scene and art direction?

### Restraint

Have unnecessary icons, cards, badges and decorative objects been removed?

### Specificity

Does the design look designed for this client rather than generated from a generic industry template?

## Critical distinction

**Reference reproduction:**

`one reference → nearly the same composition → changed content`

**Our desired workflow:**

`entire reference portfolio → extract common visual DNA → create new composition → client-specific content → same designer feeling`

The second approach is the default for all future VK covers unless the user explicitly asks for a direct reconstruction of one reference.
