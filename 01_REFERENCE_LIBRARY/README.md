# Reference Library

Store reference analyses here. A reference is not copied as artwork; its composition is reverse-engineered into reusable rules.

Each reference should document:

- composition type;
- canvas and safe-zone assumptions;
- every text block position;
- main object position and scale;
- secondary objects;
- badges and CTA elements;
- decorative elements;
- alignment and anchors;
- visual weight;
- composition logic;
- adaptation rules for a new niche.
