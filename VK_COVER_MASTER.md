# VK COVER MASTER

## 1. PURPOSE

Единый рабочий источник для создания обложек ВКонтакте.

Главная цель:

> Новая обложка должна выглядеть как естественное продолжение существующего портфолио пользователя, а не как случайный AI-баннер или готовый шаблон.

**Референсы пользователя — главный источник визуальных решений.** GitHub, Figma и другие инструменты — только техническая поддержка.

---

## 2. FORMAT & SAFE ZONE

- Desktop VK cover: **1920 × 768 px**
- Aspect ratio: **2.5 : 1**
- Работать сразу в финальном размере.
- Обложка — единая композиция, а не набор независимых UI-карточек.

### Safe zone

Safe zone **не является областью обрезки**. Полный canvas 1920×768 сохраняется.

Важные элементы — текст, логотипы, CTA и другие ключевые объекты — размещать только внутри рабочей зоны:

- **верхняя safe zone:** первые **130 px** — ничего важного не размещать;
- **нижняя safe zone:** последние **50 px** — ничего важного не размещать;
- **рабочая зона:** **Y = 130–718 px**.

Фон, фотография, атмосфера и другие полноразмерные визуальные элементы могут занимать весь canvas **1920×768**, включая safe zones.

---

## 3. CORE VISUAL DNA

Каждая обложка должна иметь:

- один главный визуальный замысел;
- один доминирующий заголовок;
- один главный герой / объект, если используется изображение;
- крупную выразительную типографику;
- осознанное негативное пространство;
- ясную визуальную иерархию;
- контролируемую глубину;
- тематическую арт-дирекцию;
- ощущение авторской работы, а не шаблона.

Текст и изображение обычно должны ощущаться как одна композиция.

Не использовать автоматически формулу:

> текст слева + человек справа + карточки снизу.

Композиция определяется выбранными референсами и конкретной задачей.

---

## 4. TYPOGRAPHY

Главный заголовок — самый сильный текстовый элемент.

Характер:

- крупный / oversized;
- сильный визуальный вес;
- высокая читаемость;
- обычно 1–2 строки, иногда 3 короткие;
- condensed display, grotesk, editorial serif или другой характерный display-шрифт — по референсам;
- высокий контраст;
- типографика может перекрываться или взаимодействовать с героем.

Нет одного обязательного шрифта для всех проектов. Шрифт выбирается по характеру ближайших референсов.

### Запрещённое направление типографики

Без прямой команды пользователя не использовать:

- tattoo-style шрифты;
- blackletter / готические шрифты;
- агрессивные tattoo brush-шрифты;
- чрезмерно декоративные рукописные шрифты;
- псевдо-гранжевые шрифты;
- шрифты с характерной татуировочной эстетикой;
- декоративную типографику, делающую обложку похожей на рекламу тату-студии.

Предпочтение отдавать чистой, современной, выразительной типографике, соответствующей конкретному референсу и нише.

### Иерархия

1. **Главный заголовок** — доминирует.
2. **Дескриптор** — только если действительно нужен.
3. **Вторичная информация** — только если предоставлена пользователем или явно поддерживается референсами.

Не придумывать текст ради заполнения пространства.

## 5. COMPOSITION LIBRARY — 30 SCHEMES

Эта библиотека создана из повторяющихся композиционных принципов, которые встречаются в предоставленных пользователем референсах. Это **не шаблоны для копирования**, а разные способы распределять текст, героя, масштаб, воздух и перекрытия.

### Жёсткое правило библиотеки

- Выбирать **одну основную схему** на обложку.
- Не смешивать 3–4 схемы одновременно без необходимости.
- Не использовать одну и ту же схему подряд без явной причины.
- При наличии референса конкретная композиция референса важнее библиотеки.
- Safe zone соблюдается во всех схемах: важный контент только **Y=130–718**.
- Полноразмерный фон может занимать весь canvas.
- В каждой схеме сохранять минимум одну явную область негативного пространства.
- Главный заголовок должен оставаться считываемым в уменьшенном размере.

### 01 — WORD WALL

Большое ключевое слово занимает 65–90% рабочей ширины. Герой или предмет частично перекрывает 1–2 буквы.

**Текст:** крупный, 1–2 строки.
**Герой:** центр / центр-смещение.
**Глубина:** герой перед частью текста.
**Безопасность:** верхняя граница заголовка начинается ниже Y=130; нижняя часть букв не опускается ниже Y=718.

### 02 — CENTRAL CUTOUT

Один крупный герой в центре, заголовок проходит за ним и частично скрывается.

**Текст:** крупный фоновой слой.
**Герой:** центральный, 35–55% canvas height.
**Негатив:** по краям.

### 03 — LEFT TYPE / RIGHT HERO

Текстовая масса слева, один крупный герой справа. Использовать только когда ближайшие референсы поддерживают такой баланс.

**Текст:** 45–55% ширины.
**Герой:** 40–50% ширины.
**Разделение:** через контраст или свет.

### 04 — RIGHT TYPE / LEFT HERO

Зеркальная композиция, но визуально не считать её отдельной схемой при выборе подряд с 03.

**Правило:** не использовать 03 и 04 последовательно без сильной причины.

### 05 — SPLIT TITLE

Заголовок разделён на две крупные части по разные стороны героя.

**Герой:** центральная ось.
**Текст:** две массивные текстовые зоны.
**Эффект:** герой становится визуальным разделителем.

### 06 — TEXT THROUGH HERO

Главный заголовок проходит через героя: часть букв находится за ним, часть — перед ним.

**Герой:** крупный.
**Текст:** широкий, 1–2 строки.
**Глубина:** обязательна.

### 07 — BOTTOM ANCHOR

Основной заголовок находится в нижней части рабочей зоны, герой или объект — выше.

**Важно:** нижний край текста ≥ 50 px от края canvas.

### 08 — TOP PRESSURE

Крупная типографика давит сверху вниз, но начинается не выше Y=130. Герой занимает нижнюю или центральную часть.

**Негатив:** оставляется вокруг героя.

### 09 — SIDE BLEED

Крупный объект выходит за боковую границу canvas, а текст занимает оставшееся пространство.

**Герой:** допускается частичный выход за левый/правый край.
**Текст:** внутри safe zone.

### 10 — FULL-WIDTH TITLE / OBJECT INTERRUPTION

Заголовок занимает почти всю рабочую ширину и прерывается объектом, который визуально пересекает строку.

**Объект:** 20–45% ширины.
**Текст:** сохраняет читаемость вокруг объекта.

### 11 — TYPOGRAPHIC FRAME

Заголовок формирует визуальную рамку вокруг героя: большие слова сверху и снизу или слева и справа.

**Герой:** центральный.
**Воздух:** вокруг рамки.

### 12 — OBJECT INSIDE WORD

Главный объект визуально помещён внутрь слова/буквенного поля и становится частью типографики.

**Важно:** не перекрывать критические части букв настолько, чтобы слово перестало читаться.

### 13 — OFFSET COLUMN

Заголовок собран в одну узкую вертикальную колонку слева или справа; герой занимает остальную ширину.

**Ширина текста:** 28–40%.
**Контраст:** через масштаб и негативное пространство.

### 14 — MASSIVE LOWER THIRD

Главный заголовок располагается в нижней трети рабочей области; сверху — крупный атмосферный герой.

**Текст:** массивный.
**Герой:** верхняя 40–55% рабочей зоны.

### 15 — MASSIVE UPPER THIRD

Заголовок формирует верхнюю часть рабочей зоны, герой занимает нижнюю.

**Важно:** верх текста начинается после Y=130.

### 16 — DIAGONAL AXIS

Основная композиционная ось идёт по диагонали. Текст и герой расположены по разным концам диагонали.

**Наклон:** используется в блоках, направляющих и объектах, но не превращает текст в хаотичный наклон.

### 17 — CENTERED EDITORIAL

Минималистичная центральная композиция: крупный заголовок, один герой, много воздуха.

**Главное:** простота и точное выравнивание.

### 18 — ASYMMETRIC OFFSET

Герой смещён далеко от центра, текст занимает противоположную массу. Баланс создаётся не симметрией, а визуальным весом.

### 19 — EDGE HERO

Герой почти полностью прижат к одному краю и частично выходит за него. Основная часть пространства остаётся типографике.

### 20 — EDGE TYPE

Типография прижата к левому или правому краю рабочей области; герой находится ближе к центру.

**Важно:** не обрезать важные буквы боковыми краями.

### 21 — MIRROR VOID

Герой и текст расположены по разным сторонам, но между ними оставляется широкий негативный канал.

**Цель:** ощущение дорогой editorial-композиции.

### 22 — OVERLAP STACK

Несколько крупных текстовых строк перекрываются с одним героем на разных глубинах.

**Ограничение:** максимум 2–3 текстовых уровня.

### 23 — CUTLINE

Главный заголовок визуально пересечён горизонтальной линией / световым слоем / краем объекта. Использовать только если это подтверждено референсной логикой.

### 24 — IMAGE AS TYPOGRAPHY

Изображение / герой частично превращается в буквенный ритм: объект проходит через буквы или повторяет направление текста.

**Важно:** читаемость слова важнее эффекта.

### 25 — GIANT WORD + SMALL DESCRIPTOR

Одно огромное слово + очень короткий вторичный дескриптор.

**Цель:** максимальный impact при минимуме текста.

### 26 — HERO DOMINATES / TYPE SUPPORTS

Герой занимает 55–70% визуального внимания, а заголовок становится крупным, но вторичным слоем.

**Использовать:** для сильных предметных или портретных изображений.

### 27 — TYPE DOMINATES / HERO SUPPORTS

Типографика занимает 65–80% визуального внимания, герой — небольшая, но очень выразительная часть композиции.

**Использовать:** когда название бренда/услуги является главным продуктом.

### 28 — TWO-SCALE TYPE

Одна строка экстремально большая, вторая заметно меньше и служит контрастом.

**Правило:** максимум два основных размера заголовочного текста.

### 29 — FOCAL WINDOW

Большой заголовок создаёт вокруг героя визуальное «окно»: свободное пространство или форма окружает объект.

**Герой:** внутри окна.
**Текст:** формирует границы пространства.

### 30 — CLEAN ASYMMETRY

Один огромный текстовый массив + один крупный объект, но оба смещены относительно центра. Никаких дополнительных блоков.

**Цель:** современная editorial-композиция с сильным визуальным напряжением.

---

## 6. SCHEME SELECTION / ANTI-REPETITION

При создании новой обложки:

1. Сначала выбрать схему по референсу или задаче.
2. Если конкретного референса нет — выбрать одну схему из библиотеки, которая ещё не использовалась в последних работах.
3. Не повторять одну и ту же композицию в двух соседних обложках.
4. Не считать простое зеркальное отражение новой схемой.
5. Не возвращаться автоматически к `LEFT TYPE / RIGHT HERO`.
6. Изменять хотя бы **2 из 4 параметров** при новой работе:
   - позиция героя;
   - масштаб героя;
   - позиция заголовка;
   - направление / ось композиции.
7. Перед финализацией сравнить новую работу с предыдущими и убедиться, что silhouette композиции отличается.

---

## 7. GRID, ALIGNMENT & TEXT CLEARANCE

Перед композицией определить:

- основные вертикальные оси;
- горизонтальные уровни;
- зону заголовка;
- зону героя;
- негативное пространство.

Использовать сетку и направляющие. Выравнивание — обязательная часть профессиональной сборки.

### TEXT CLEARANCE

Фон и герой должны учитывать будущую типографику.

Если объект мешает чтению заголовка:

- изменить его положение;
- затемнить;
- размыть;
- убрать;
- создать свободное пространство.

Не спасать перегруженный фон большой плашкой под текстом, если этого нет в референсе.

---

## 8. BACKGROUND / HERO

Фон подбирается под нишу и ближайшие референсы.

Он может быть фотографическим, интерьерным, архитектурным, предметным, абстрактным, текстурным или атмосферным.

Герой должен принадлежать среде через:

- свет;
- цветокоррекцию;
- тени;
- дымку;
- глубину;
- атмосферное смешение.

Не просто вставлять вырезанный объект на фон.

Если у человека или объекта есть выраженное направление взгляда / движения, по возможности направлять его к главному сообщению, если это усиливает композицию.

---

## 9. DEPTH & LAYERING

Использовать несколько глубинных планов:

**BACKGROUND → ATMOSPHERE → SECONDARY ELEMENTS → HERO → TYPOGRAPHY → FOREGROUND**

Элементы могут находиться перед или за текстом.

Использовать:

- перекрытия;
- перспективу;
- размытие;
- тени;
- свет;
- масштаб;
- частичное кадрирование.

Не помещать все элементы в одну плоскость.

---

## 10. LIGHT

Свет — часть композиции, а не случайный декоративный эффект.

Он должен:

- отделять героя от фона;
- направлять внимание;
- создавать глубину;
- связывать героя, фон и типографику;
- усиливать акцентный цвет.

Допустимы rim light, backlight, мягкое свечение, атмосферная дымка, volumetric light и локальные световые акценты, если они поддержаны референсом.

Не добавлять световые эффекты без композиционной функции.

---

## 11. COLOR

Обязательной палитры нет.

Цвет определяется референсами, брендом и темой.

Акцентный цвет используется экономно и только там, где усиливает иерархию.

Не добавлять цвет просто потому, что он кажется «премиальным» или красивым.

---

## 12. DECORATION

Декоративные элементы допустимы только если они подтверждены референсом или имеют понятную композиционную функцию.

Текстура, зерно, дымка, световые акценты, тематические объекты, линии, рамки и атмосферные элементы допустимы только при необходимости.

Не превращать композицию в набор случайных AI-декораций.

---

## 13. INFORMATION DENSITY

Приоритет:

**MAIN MESSAGE → HERO → SECONDARY MESSAGE → SMALL FACTS**

Информация должна читаться за один взгляд.

Не добавлять дополнительные блоки только потому, что есть свободное место.

---

## 14. STRICTLY DO NOT ADD

Не добавлять автоматически:

- карточки преимуществ;
- «Почему мы»;
- FAQ;
- service grids;
- icon grids;
- большие website-style CTA;
- случайные стрелки или круги;
- glassmorphism-карточки;
- лишние badges;
- десятки мелких подписей;
- фейковые статистики;
- бессмысленный декоративный текст;
- случайные 3D-объекты;
- абстрактные blobs;
- шаблонные UI-панели;
- чрезмерные градиенты;
- fake logos / fake brands;
- придуманные услуги;
- random premium gold details;
- элементы, которых нет в референсной логике.

CTA, badges, icons и дополнительные подписи использовать только если они явно нужны по референсу или предоставлены пользователем.

---

## 15. WORK MODES

### TYPOGRAPHY ONLY

Создавать только типографический asset:

- без фона;
- без фотографий;
- без людей;
- без продуктов;
- без окружения;
- без иконок;
- без CTA;
- без придуманного дополнительного текста;
- прозрачный фон, если инструмент поддерживает;
- фокус на шрифте, весе, масштабе, наклоне, интервалах и положении.

### BACKGROUND ONLY

Создавать только визуальную сцену / hero:

- без текста;
- без логотипов;
- без CTA;
- без badges;
- без придуманного текста;
- оставить негативное пространство под утверждённую типографику;
- композиция и свет должны учитывать её положение.

### FINAL ASSEMBLY

Объединить утверждённую типографику и утверждённый фон / hero.

Использовать Figma или другой layout-инструмент для точных координат, масштаба, spacing, layer order и редактируемой типографики.

Не менять утверждённые элементы без отдельной команды.

---

## 16. FINISHING ORDER

Собирать в таком порядке:

1. композиция;
2. типографика;
3. герой;
4. глубина и перекрытия;
5. свет;
6. цветовой баланс;
7. текстура;
8. финальная коррекция.

Текстура и эффекты не должны маскировать слабую композицию.

### FINAL COLOR CHECK

Проверить:

- контраст;
- светлые области;
- тени;
- температуру;
- насыщенность;
- общий цветовой баланс;
- виньетирование при необходимости;
- зерно / текстуру при необходимости.

Финальная коррекция должна объединять все элементы в одну сцену.

---

## 17. GITHUB / TOOLKIT RULE

GitHub и технические инструменты используются для улучшения процесса, автоматизации и production workflow.

Они **не определяют визуальный стиль**.

Визуальные решения всегда подчиняются референсам пользователя и этому MASTER-файлу.

## 18. VISUAL QC

Перед финализацией проверить:

- [ ] размер 1920×768;
- [ ] важные элементы находятся только внутри Y=130–718;
- [ ] верхние 130 px не содержат важного текста, логотипов или других ключевых элементов;
- [ ] нижние 50 px не содержат важного текста, логотипов или других ключевых элементов;
- [ ] фон может занимать весь canvas 1920×768;
- [ ] один главный визуальный замысел;
- [ ] главный заголовок читается мгновенно;
