# VK COVER REFERENCE DNA

## PURPOSE

This file records the **visual patterns actually observed in the user's VK cover reference portfolio** and converts them into reusable design knowledge.

It works together with:

- `VK_COVER_MASTER.md` — hard rules and production constraints.
- `VK_COVER_DESIGNER_MIND.md` — decision-making and design judgment.
- `VK_COVER_REFERENCE_DNA.md` — what the reference portfolio visually does.

This is **not a template library**. It is a record of recurring visual behavior.

Important: this document must describe only patterns supported by the supplied reference set and established analysis. It must not invent details that were not observed.

---

# 1. CORE DNA OF THE REFERENCE PORTFOLIO

The references consistently feel like **designed advertising compositions**, not ordinary social-media banners and not generic AI advertisements.

The strongest common traits are:

- one clear visual idea;
- one clear primary visual focus;
- clean, controlled typography;
- moderate rather than automatically gigantic headline scale;
- compact information pills when useful;
- restrained information density;
- a background that behaves like a composed visual scene;
- deliberate negative space;
- strong object-to-type relationship;
- controlled depth;
- intentional edge crops;
- a clear visual hierarchy that works at a distance.

The references do **not** rely on one universal formula such as:

> text left + person/product right.

Their similarity comes from **design discipline**, not from repeating one layout.

---

# 2. WHAT A REFERENCE FEELS LIKE AS A WHOLE

When viewed as a thumbnail, a successful reference usually has an immediately recognizable silhouette.

The viewer should perceive:

1. the category / visual world;
2. the main visual subject;
3. the main title or typographic mass;
4. the overall mood.

The composition does not need to be complicated to be strong.

A relatively simple structure can look professional when:

- the hero is chosen correctly;
- the background supports it;
- the type scale is controlled;
- information is economical;
- the empty space is intentional.

---

# 3. TYPOGRAPHIC DNA

## 3.1 HEADLINE

The headline is important, but **"make it enormous" is not a defining rule of the references**.

The observed behavior is:

- clean;
- readable;
- visually dominant enough to establish hierarchy;
- proportionate to the scene;
- integrated with the visual hero;
- not overloaded with decorative effects.

The headline can be large, but its strength comes from **scale relationships, font character, contrast, placement and surrounding space**, not size alone.

## 3.2 OVERLINE

A small upper text level appears in some reference structures.

It is optional and contextual.

It can establish:

- brand/category;
- context;
- a small introductory label.

It must never be added mechanically.

## 3.3 SUPPORTING TEXT

Supporting text is compact and secondary.

The references favor a small amount of useful information rather than a paragraph-heavy banner.

## 3.4 FONT CHARACTER

The references favor **clean, professional, modern typography**.

The portfolio should not be interpreted as requiring tattoo typography, blackletter, gothic lettering or aggressive decorative fonts.

---

# 4. PILL / INFORMATION DNA

Compact information pills are an important recurring visual device in the reference system.

They are not website cards.

Their role is twofold:

1. communicate a small piece of information;
2. help balance the composition.

Common structural behavior observed in the reference examples includes:

- one compact pill;
- two compact pills;
- small information blocks placed around the main composition;
- a small upper label combined with one or more pills.

The number of pills is **not fixed**.

The correct question is:

> Does this information improve both communication and composition?

If not, remove it.

---

# 5. BACKGROUND DNA — MOST IMPORTANT

The reference backgrounds should not be understood as:

> "a nice photo selected for the niche."

They behave more like **advertising key visuals**.

The scene is constructed around the visual subject and the future typography.

Typical logic:

**environment / base → hero → supporting depth → foreground / edge crops → light → atmosphere → controlled text space**

However, this is a **logic of construction, not a mandatory checklist**.

A reference can be visually simple if the composition already has enough depth and structure.

---

# 6. THE HERO IS IN THE SCENE

A major characteristic of the reference style is that the hero should feel physically integrated into the environment.

Avoid the appearance of:

> isolated PNG object + generic background.

Integration may come from:

- contact shadow;
- surface contact;
- perspective;
- reflection;
- consistent light direction;
- atmospheric depth;
- color interaction with the environment;
- occlusion by foreground elements.

The exact technique changes by niche.

---

# 7. FOREGROUND / MIDGROUND / BACKGROUND

The references use depth deliberately.

### BACKGROUND

Usually calmer, softer or less visually dominant.

May contain:

- environment;
- architecture;
- large blurred shapes;
- thematic textures;
- distant objects.

### MIDGROUND

Provides context and depth.

May contain related objects or environmental details.

### FOREGROUND

Carries the strongest physical presence.

May contain:

- the hero;
- a surface;
- cropped objects;
- contact shadows;
- large partial details.

These levels should be used **only when they improve the composition**.

---

# 8. EDGE-CROP DNA

Objects entering from the edges are an important tool for making the frame feel larger than the visible canvas.

Useful patterns include:

- large partial object at left edge;
- large partial object at right edge;
- foreground object entering from bottom;
- large background element cropped by the frame;
- partial secondary object behind the hero.

The edge crop should feel intentional and physically believable.

Do not add random cropped objects simply to imitate editorial complexity.

---

# 9. NEGATIVE SPACE DNA

Empty space is deliberately designed.

The references often leave areas that are visually calmer so that:

- the headline can breathe;
- the hero remains dominant;
- the composition does not become noisy;
- the eye has a place to rest.

Negative space is therefore a **positive design element**.

Never fill it merely because it is empty.

---

# 10. RELATION BETWEEN HERO AND TYPE

The references use several relationships rather than one fixed layout.

Possible observed logic:

- hero separated from text;
- hero visually balanced by text;
- hero overlaps the text area;
- text sits in a calm area created by the scene;
- hero and headline form one visual mass;
- supporting objects balance the opposite side of the headline.

The correct relationship is chosen according to the image and concept.

Do not force the hero to one side of the canvas.

---

# 11. BACKGROUND COMPOSITION SHOULD BE READ WITHOUT TEXT

A critical reference test:

> **Remove the headline and pills mentally. Does the remaining background still look like an intentional advertising scene?**

If the answer is no, the background is probably only a decorative photo.

A strong reference background has:

- a clear subject;
- spatial hierarchy;
- believable physical placement;
- intentional crop;
- controlled light;
- enough calm space for typography.

---

# 12. WHAT THE REFERENCES DO NOT DO

Do not infer the following as mandatory reference behavior:

- giant headline on every cover;
- text always on the left;
- person always on the right;
- one product always centered;
- mandatory interior background;
- mandatory luxury aesthetic;
- mandatory black/gold palette;
- mandatory smoke or glow;
- mandatory 2–3 secondary objects;
- mandatory pills;
- mandatory CTA;
- mandatory icons;
- mandatory cards.

These are generic advertising conventions and should not be confused with the user's reference DNA.

---

# 13. DENSITY

The reference style is generally **controlled rather than maximalist**.

The composition can contain several visual elements while still feeling clean because:

- secondary elements are small;
- hierarchy is clear;
- the hero remains obvious;
- background activity is controlled;
- text is economical;
- empty space is preserved.

The goal is not minimalism for its own sake.

The goal is **controlled visual density**.

---

# 14. LIGHTING DNA

Lighting should support the composition.

Do not use cinematic effects merely because they look impressive.

Use light to:

- separate the hero;
- support the headline area;
- establish depth;
- create material realism;
- direct the eye;
- connect foreground and background.

If the reference has a strong color-lighting system, extract that logic rather than automatically applying a generic cinematic grade.

---

# 15. MATERIAL AND PHYSICAL REALISM

Products and people should belong to the same physical scene.

Important signals include:

- contact;
- scale;
- perspective;
- light direction;
- shadow softness;
- reflection behavior;
- depth of field;
- atmospheric integration.

This is particularly important for product-led references.

---

# 16. COMPOSITION FAMILIES

The reference set should be interpreted as several families rather than one template.

### FAMILY A — HERO + CLEAN TYPE

One strong hero, clean headline, little secondary information.

### FAMILY B — HERO + TYPE + ONE PILL

A compact information pill is used to complete or balance the composition.

### FAMILY C — HERO + TYPE + TWO PILLS

Two compact information units create additional balance.

### FAMILY D — OVERLINE + HERO + TITLE

Small contextual label above the main headline.

### FAMILY E — OVERLINE + TITLE + PILLS + HERO

Several information levels remain compact and controlled.

### FAMILY F — PRODUCT / OBJECT SCENE

The object is integrated into a composed physical environment rather than isolated.

### FAMILY G — MULTI-OBJECT COMPOSITION

Two or more related objects create one visual mass or a deliberate relationship.

### FAMILY H — HERO + CROPPED EDGE ELEMENTS

The main subject is supported by large partial objects entering from the edges.

These families are not rigid templates. They are starting points for design judgment.

---

# 17. HOW TO ADAPT A REFERENCE TO A NEW NICHE

Do not copy the literal subject.

Preserve the **relationship between variables**.

For example, if a reference has:

- one dominant product;
- one supporting partial product;
- calm text area;
- two compact information pills;
- strong foreground contact;

then a new niche can preserve those relationships while replacing the subject with a relevant product.

The goal is:

**same design intelligence, new content.**

Not:

**same picture, new object.**

---

# 18. REFERENCE ANALYSIS PROTOCOL

When a reference is attached, analyze it in this order:

### PASS 1 — SILHOUETTE

Ignore details.

Identify:
- dominant mass;
- empty mass;
- visual axis;
- first focal point.

### PASS 2 — HERO

Identify:
- main subject;
- scale;
- crop;
- position;
- physical integration.

### PASS 3 — SCENE

Identify:
- background environment;
- surface;
- midground objects;
- foreground objects;
- edge crops;
- depth.

### PASS 4 — TYPE

Identify:
- overline;
- headline;
- supporting text;
- type scale;
- type character;
- relationship to hero.

### PASS 5 — INFORMATION

Identify:
- number of pills;
- size;
- shape;
- placement;
- information hierarchy.

### PASS 6 — LIGHT / COLOR

Identify:
- dominant palette;
- accent color;
- light direction;
- contrast hierarchy;
- atmosphere.

### PASS 7 — DESIGN JUDGMENT

Answer:

> Why does this composition feel intentional rather than generic?

This answer is more important than any single coordinate.

---

# 19. REFERENCE-TO-NEW-COVER TRANSLATION

When building a new cover from a reference:

### KEEP

- compositional logic;
- hierarchy;
- density;
- object-to-type relationship;
- scene depth logic;
- negative-space logic;
- information economy;
- overall design confidence.

### CHANGE

- subject;
- exact objects;
- exact wording;
- exact colors when needed for the new brand;
- exact crop;
- exact scene;
- exact typeface;
- exact placement.

The result should be recognizably related in **design thinking**, not visually copied.

---

# 20. REFERENCE-BASED ANTI-REPETITION

Two covers can use the same family and still feel different if their internal decisions change.

Track at least:

- hero scale;
- hero position;
- hero count;
- edge-crop strategy;
- background structure;
- negative-space location;
- type hierarchy;
- pill count;
- visual axis;
- density;
- light direction.

Do not repeatedly use the same combination.

Changing only the product, color or background photo is **not** enough.

---

# 21. THE REFERENCE STANDARD

A successful new cover should pass three levels:

### LEVEL 1 — TECHNICAL

It obeys `VK_COVER_MASTER.md`.

### LEVEL 2 — VISUAL

It follows the reference portfolio's observed discipline:

- clear hero;
- clean type;
- controlled information;
- composed background;
- intentional negative space;
- believable depth.

### LEVEL 3 — AUTHORSHIP

It feels like a new work made by the same designer, not:

- a copy of the reference;
- a generic AI advertisement;
- a template with a different niche.

---

# 22. FINAL REFERENCE TEST

Before approving a concept, ask:

> If I removed the text, would the background still have a deliberate composition?
>
> If I removed the background, would the typography and information still have a clear hierarchy?
>
> If I replaced the hero with another relevant object, would the design logic still make sense?
>
> Does the composition have a recognizable silhouette?
>
> Is there unnecessary information?
>
> Is the headline larger than necessary just to create drama?
>
> Are the pills actually useful?
>
> Does the hero feel physically integrated?
>
> Does this look like a new portfolio piece rather than a generated banner?

If any answer is weak, rethink the concept before rendering.

---

# 23. IMPORTANT LIMITATION

This file is derived from the reference patterns that have been explicitly observed and discussed in the working conversation.

It must not claim that every listed characteristic appears in every reference.

The correct use is:

> **treat these as recurring DNA and decision patterns, then verify the exact reference before adapting it.**

When a specific attached reference contradicts a general pattern in this file, the specific reference should win for that individual task, while hard constraints from `VK_COVER_MASTER.md` remain mandatory.
