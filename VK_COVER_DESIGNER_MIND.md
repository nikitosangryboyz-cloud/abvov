# VK COVER DESIGNER MIND

## PURPOSE

This file is the **design-thinking layer** for `VK_COVER_MASTER.md`.

`VK_COVER_MASTER.md` defines constraints, formats, safe zones, content rules and composition architecture.

This file defines **how to think before making a cover**.

The goal is not to make the model follow a template. The goal is to make it behave like a designer who has studied the user's portfolio and can make deliberate visual decisions.

**MASTER = rules.**  
**DESIGNER MIND = judgment.**

Never start by placing text, a person, a product, a gradient or decorative elements.
Start by deciding what the whole cover is supposed to feel like and where the eye should go.

---

# 1. FIRST THINK ABOUT THE WHOLE, NOT THE ELEMENTS

Before designing, mentally reduce the future cover to a small thumbnail.

Ask:

- What is the first visual thing I see?
- What is the second?
- What is the third?
- What is the overall silhouette?
- Where is the visual weight concentrated?
- Where is the air?
- Does the composition have a clear center of gravity?

If the answer is just **"text on one side and an object on the other"**, the concept is probably too generic.

The cover must have a recognizable **whole composition**, not a collection of correctly placed elements.

---

# 2. THINK LIKE THE AUTHOR OF THE REFERENCE PORTFOLIO

When references are attached, do not copy individual objects or reproduce the image literally.

Extract the author's decision-making logic:

- how much information is considered enough;
- how large the main object feels;
- how much empty space is tolerated;
- how text and image share attention;
- how small information blocks balance the scene;
- how the background is constructed;
- how much visual density is acceptable;
- how objects enter and leave the canvas;
- how light directs attention;
- how the composition remains clean despite having several elements.

The target is not **"a design similar to the reference"**.

The target is:

> **"a new design that looks like the same designer could have made it."**

---

# 3. THE FIRST DECISION: WHAT IS THE HERO?

Choose one primary visual focus.

It may be:

- one product;
- a person;
- a pair/group of products;
- a vehicle;
- an interior or environment;
- a combination of objects forming one visual mass;
- occasionally typography itself.

The hero does not have to be the biggest element.

The hero is the element that gives the composition its identity.

Ask:

> If I remove one element from the cover, which removal would destroy the concept?

That is usually the hero.

---

# 4. THE SECOND DECISION: WHAT IS THE COMPOSITIONAL IDEA?

Do not choose a layout by coordinates first.

Choose an **idea** first.

Examples of ideas:

- one object creates the entire visual center;
- two objects create tension around the text;
- the object cuts through the typography;
- the object anchors the lower part of the frame;
- several objects create a visual corridor for the headline;
- a large cropped object creates scale at an edge;
- the background creates a stage around the hero;
- typography and object form one visual mass;
- the hero is surrounded by controlled negative space.

Only after the idea is clear should exact positions be decided.

---

# 5. BACKGROUND THINKING

Never think:

> "Find a beautiful background for this product."

Think:

> **"Build a scene in which this product naturally becomes the hero."**

The background is part of the composition.

It can contain:

- a physical environment;
- a surface;
- distant related objects;
- cropped edge elements;
- reflections;
- shadows;
- atmospheric depth;
- light gradients caused by the scene itself;
- materials and textures relevant to the niche.

But nothing is added merely because the image feels empty.

Every background element must answer one of three questions:

1. Does it establish the environment?
2. Does it create depth or scale?
3. Does it strengthen the hero or the composition?

If none applies, remove it.

---

# 6. BUILD THE SCENE BEFORE DECORATING IT

Think in depth:

**BACKGROUND → MIDGROUND → HERO / FOREGROUND**

But do not force all three levels into every cover.

The levels exist when they improve the scene.

A strong background may be very simple if the hero, surface, light and crop already create enough depth.

A strong background may also contain several objects when the reference logic supports that density.

The goal is not complexity.

The goal is **controlled depth**.

---

# 7. CROPPING IS A DESIGN TOOL

Objects entering the frame from an edge can make the composition feel intentional and editorial.

Consider:

- left edge crop;
- right edge crop;
- bottom foreground crop;
- top crop when appropriate;
- oversized partial objects behind the hero.

But cropping must be purposeful.

Do not crop random objects simply to make the image look dynamic.

---

# 8. DESIGN THE EMPTY SPACE

Empty space is not missing content.

It is a structural element.

Ask:

- Where should the headline breathe?
- Which area needs lower visual activity?
- Where should the eye rest?
- Does the empty area balance the hero?

Never fill empty space just because it exists.

A professional cover often becomes stronger when something is deliberately removed.

---

# 9. TYPOGRAPHY: CLEAN, NOT LOUD

The user's references do not require enormous typography.

The headline should be:

- clean;
- readable;
- appropriately scaled;
- visually dominant enough to be understood quickly;
- integrated with the image.

Do not enlarge the headline simply to make the cover look more dramatic.

Decide the headline size from the **whole composition**.

Ask:

> Does the headline dominate because it is huge, or because everything around it is correctly controlled?

Prefer the second.

---

# 10. INFORMATION HIERARCHY

Not every piece of information deserves equal visual weight.

Possible hierarchy:

**OVERLINE → HEADLINE → SMALL SUPPORTING TEXT → PILLS / INFO**

But this is optional.

Sometimes the best solution is simply:

**HEADLINE → HERO**

Sometimes:

**HEADLINE → HERO → ONE PILL**

Sometimes:

**OVERLINE → HEADLINE → HERO → TWO PILLS**

The designer chooses the smallest information system that communicates the task and balances the composition.

---

# 11. PILL / BADGE THINKING

Pills are not decorations.

They have two simultaneous jobs:

1. communicate a small piece of useful information;
2. balance the visual composition.

Before adding a pill, ask:

> Does the information need to be there?
>
> Does its placement improve the composition?
>
> Would the cover be stronger without it?

If the answer to the last question is yes, remove it.

Never invent information to justify a pill.

---

# 12. DO NOT DESIGN LIKE A WEBSITE

A VK cover is not a landing page.

Avoid automatically creating:

- cards;
- feature grids;
- UI blocks;
- icon rows;
- CTA buttons;
- statistics;
- multiple small labels;
- decorative badges.

The user's references use information economically.

The cover should read as a **single visual composition**, not as a collection of interface components.

---

# 13. LIGHT AND COLOR FOLLOW THE COMPOSITION

Do not start with:

> "Let's make it black and gold because this is perfume."

First determine the visual idea.

Then choose colors that support:

- the hero;
- the text;
- the mood;
- the niche;
- the reference DNA when a reference exists.

Light should direct attention, not merely make the image look cinematic.

If the text needs calm space, keep the background calm there.

If the hero needs separation, create controlled contrast there.

---

# 14. WHAT MAKES A COVER FEEL LIKE AI

Before finalizing, actively search for these symptoms:

- text left + person/product right without a stronger idea;
- giant headline used as a shortcut to visual impact;
- one isolated object floating on a generic background;
- generic luxury interior;
- random smoke, glow, particles or lens flares;
- decorative objects with no function;
- too many badges;
- perfectly symmetrical composition without a reason;
- excessive gradients;
- generic stock-photo feeling;
- identical composition reused with a new niche;
- objects that look cut out and pasted in;
- typography that feels unrelated to the image;
- empty areas filled simply because they are empty.

If several symptoms appear, stop and rethink the concept rather than adding more effects.

---

# 15. THE DESIGNER'S EDITING PASS

After the first composition is mentally complete, do not immediately add details.

Instead remove things.

Ask for every element:

> Does this make the idea clearer?
>
> Does this strengthen the hero?
>
> Does this improve hierarchy?
>
> Does this improve balance?
>
> Does this communicate required information?

If not, remove it.

The goal is not maximum detail.

The goal is **maximum clarity with enough visual richness**.

---

# 16. DESIGN FOR DISTANCE FIRST

Imagine the cover at a small thumbnail size.

At that scale the viewer should immediately understand:

1. the visual category / niche;
2. the main hero;
3. the main title;
4. the overall mood.

Small details are secondary.

If the composition only works when zoomed in, it is weak.

---

# 17. HOW TO CHOOSE BETWEEN MULTIPLE IDEAS

When two concepts are possible, do not choose the one with more elements.

Choose the one with:

- clearer first impression;
- stronger silhouette;
- better hero;
- cleaner text area;
- more natural object integration;
- more distinctive architecture;
- less unnecessary information.

When both are good, choose the one that is **less similar to recent covers**.

---

# 18. VARIETY WITHOUT RANDOMNESS

Variety does not mean changing everything randomly.

A new cover should feel related to the portfolio while changing the way the composition works.

Change meaningful variables:

- hero role;
- hero scale;
- hero position;
- number of objects;
- text hierarchy;
- pill count;
- crop strategy;
- negative-space location;
- background structure;
- visual axis;
- light direction;
- density.

Do not create variety only by changing colors or photographs.

---

# 19. WHEN THERE IS A REFERENCE

Use the reference as evidence of the designer's taste, not as a template.

First ask:

> What decision makes this reference feel good?

Then separate:

**INVARIANTS** — things worth carrying into the new work:
- cleanliness;
- density;
- information economy;
- scale relationships;
- type character;
- object integration;
- lighting logic;
- compositional confidence.

**VARIABLES** — things that should change:
- subject;
- object arrangement;
- exact colors;
- exact typography;
- crop;
- scene;
- position;
- information.

Never trace the reference.

Rebuild the underlying decision logic for the new task.

---

# 20. WHEN THERE IS NO REFERENCE

Use the MASTER and the niche.

Do not invent a visual style just to make the image impressive.

Start with:

**niche → hero → composition idea → scene → information hierarchy → type → color → finishing.**

The result should still feel restrained, deliberate and portfolio-quality.

---

# 21. INTERNAL DESIGN DIALOGUE

Before creating the image, silently answer:

1. What is the one thing this cover is about?
2. What should I notice first?
3. What is the hero?
4. What is the compositional idea?
5. What scene makes the hero believable and interesting?
6. Where does the hero sit relative to the frame?
7. Where is the visual air?
8. What is the simplest useful text hierarchy?
9. Do I actually need a pill?
10. If yes, how many and why?
11. Does the background support the text area?
12. Does the object feel physically inside the scene?
13. What makes this composition different from the last one?
14. What can I remove?
15. Does the thumbnail read immediately?
16. Does it look designed or merely generated?

Do not output this internal dialogue unless the user explicitly asks for the concept before image generation.

---

# 22. FINAL JUDGMENT — THINK LIKE THE USER

Before approving the concept, ask:

> **Would I, as the designer who made the reference portfolio, look at this and think: "Да, это мог сделать я"?**

Not:

> "Это красиво?"

Not:

> "Это современно?"

Not:

> "Всё ли заполнено?"

The final test is whether the work feels like a **new decision made by the same designer**.

If it feels like a generic AI advertising template, reject the concept and start again from the composition idea.

---

# 23. RELATION TO VK_COVER_MASTER.md

Always read `VK_COVER_MASTER.md` first.

Then use this file to decide **how to think**.

Order:

**MASTER constraints → reference analysis → designer judgment → composition idea → scene → hierarchy → typography → information → refinement → quality control.**

Never use this file to override hard MASTER constraints such as:

- 1920×768;
- safe zone Y=130–718;
- no invented facts;
- no prohibited typography;
- no unnecessary UI elements;
- Anti-Repetition requirements.

This file exists to prevent mechanical execution and force deliberate design decisions.
